The important update is therefore not "add BM25 in front of JEPA." It is:
Base-only JEPA is now the empirical control arm.
Every added mechanism must win against it.
The benchmark should separate:
• routing value — correct skill, skill-set, or abstention;
• runtime value — latency, throughput, memory;
• downstream value — whether the route changed task success;
• generalization value — whether gains survive unseen contexts.
