## 5. Byte vs token essay (p08-11)
- Tokenizer = compression before cognition; static sparsifier frozen outside runtime reasoning ("primitive skill system"). Bytes = substrate, tokens = cached compression, skills = larger cached compression, graphs = structural, JEPA = predictive compression.
- Byte model: no OOV, but sequence length explodes -> must discover higher-order units internally.
- Proposed: neither token nor byte; dynamic chunking -> latent units -> concept nodes -> skills -> Sparse-Savant frontier -> reasoning = hierarchical adaptive compression. Levels: BYTE (lossless input) -repeated structure-> CHUNK (learned local compression) -semantic-> LATENT/TOKEN-LIKE -task relevance-> GRAPH (entities + relations) -repeated procedure-> SKILL (reusable computation) -objective-> SPARSE-SAVANT (active subset) -predicted utility-> JEPA (next-state prediction).
- "Tokens are microscopic skills": bytes -> token "thermodynamics" -> graph node -> skill solve_thermodynamic_problem -> macro-skill physical_system_analysis. Compression all the way up: promote configs seen often enough.

## 6. Multiscale Numogram (p15-16)
- U(x) extended down: raw bytes -> cheap local encoder -> detect structure -> ordinary text compress hard | novel identifier preserve | code syntax preserve | boilerplate collapse | unusual pattern investigate. Sparse-Savant becomes multiscale: "at what resolution does this info deserve attention?"
- Numogram recursive per level: BYTE/CHUNK/CONCEPT/SKILL/REASONING/CODE numograms (which X deserve Y?). Primitive: information -> detect structure -> compress predictable -> preserve surprising -> allocate compute.
- Bet: raw bytes -> cheap local -> adaptive segmentation (tiny/med/large chunks) -> latents -> sparse routing -> expert/skill | predictive world state -> selective reasoning. Gone: fixed tokenizer, fixed semantic resolution, uniform compute.
- Self-modifying: "skill-jepa" repeated usage -> temporary chunk -> persistent latent -> graph node -> skill -> expert; reverse: unused skill -> low utility -> demote -> compress -> keep only underlying representation = adaptive representational granularity.
- Missing (doc): whether hierarchy beats simpler arch at equal compute. Flip: learned chunking costs more than fixed tokenization saves. Confidence mu .90.
