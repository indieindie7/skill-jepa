# A13b: session-aware shrink selection (2026-10-30)

Script: a13b_shrink.py (+ a13b_agg.py). Raw: data/a13b-s0.json, a13b-s1.json, aggregate data/a13b-20261030.json, gate data/a13b-gate-20261030.json. CPU only, 2 seeds.

## Method
Pool = TRAIN+VAL rows of each split (shrink.setup; shrink.part now also returns idx/k). Grouped 5-fold by sid; folds balanced on labelled rows (46 sids, only 13 have labelled rows; plain random sid folds gave a fold with 0 labelled rows -> NaN). Per fold: head trained on 4/5 sids (inner ~20% labelled sids as early-stop val), scored on held-out fold; CV hit1 = head argmax hit1 on labelled held-out rows, mean over folds, then over seeds. TEST hit1/acc (shrink.evaluate, 1 run per seed) = reference only.

## Caveats
- CV noise: seed sd ~.02 on CV vs .005 margin; baseline CV swings .386/.429 (time), .452/.483 (session). Margin is inside noise, so "holds" is weak evidence either way.
- Only 13 sids carry labels; folds are label-balanced but dominated by few big sessions (586de7b7 = 282 labelled rows).
- CV metric = head-only argmax hit1 (no A0 pool combine, no delta); TRAIN-part rows use LOO kNN energies, VAL-part rows use train-kNN energies (mixed in pool); fold heads see kNN-feature leakage of held-out neighbours via LOO energies.
- Drop runs: single seed each, different base arm per seed; bm25 s1 drop unfinished.
- Holdout gap .010 is ~ the 9a20c4c gap; deterministic-ish: width carries a small holdout-hit1 edge, d16b0 gains on time split but loses on session B1 test.
- Nothing committed; prod head/trace state untouched.
